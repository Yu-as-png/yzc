# 微头条 · 网页 B/S 版 — 业务流程图

## 1. 应用启动与路由守卫流程

```mermaid
flowchart TD
    A[浏览器访问 http://localhost:5173] --> B[main.js createApp<br/>use router mount #app]
    B --> C[router.beforeEach 触发]
    C --> D{localStorage 有 token?}
    D -- 无 & 目标非 public --> E[重定向 /login?redirect=原路径]
    D -- 有 --> F[放行目标路由]
    D -- 无 & 目标是 /login --> F
    G{访问 /login 且已登录?} -- 是 --> H[重定向 /]
    F --> I[App.vue 渲染 Nav + router-view]
    E --> I
```

## 2. 登录 / 注册流程（sequenceDiagram）

```mermaid
sequenceDiagram
    participant U as 用户(浏览器)
    participant L as Login.vue
    participant A as api.js(fetch /api)
    participant P as Vite proxy → NestJS :3000

    U->>L: 填用户名/密码，点击登录
    L->>L: 前端校验非空
    L->>A: api.post('/auth/login')
    A->>P: POST /api/auth/login
    alt 成功
        P-->>A: {code:0, data:{token, user}}
        A-->>L: 返回 data
        L->>L: localStorage 存 token / user
        L-->>U: router.push(redirect 或 /)
    else 失败
        P-->>A: {code:1, msg}
        A-->>L: throw Error(msg)
        L-->>U: 页面显示 err
    end
    opt 注册
        U->>L: 昵称 + 两次密码
        L->>L: 校验昵称非空、两次密码一致
        L->>P: POST /api/auth/register
        P-->>L: code:0
        L-->>U: 自动切回登录模式
    end
```

## 3. 首页浏览流程

```mermaid
flowchart TD
    A[Home.vue onMounted] --> B[Promise.all 并行请求<br/>/notices + /types + /headlines?sort=like 热榜]
    A --> C[route.query.q 作为初始关键字]
    B & C --> D[load: GET /headlines?keyword&typeId&sort&page&pageSize]
    D --> E[渲染信息流 + 频道栏 + 热榜 + 公告]

    F --> H[切换排序 select]
    F --> I[上一页/下一页]
    F --> J[导航栏搜索 → route /?q=]
    G & H & I & J --> D
    F --> K[点击条目 → /headlines/:id 详情]
    F --> L[展开公告搜索 → GET /notices?keyword]
```

## 4. 详情页：浏览 / 点赞 / 评论 / 回复 / 删除（sequenceDiagram）

```mermaid
sequenceDiagram
    participant U as 用户
    participant D as Detail.vue
    participant S as NestJS(经 Vite 代理)

    U->>D: 打开 /headlines/:id
    D->>S: GET /api/types
    D->>S: GET /api/headlines/:id（view_count+1）
    D->>S: GET /api/headlines/:id/comments
    S-->>D: 详情 + 全部评论
    D->>D: topComments / childrenOf 组装楼中楼

    U->>D: 点击 点赞/已赞
    D->>S: POST /api/headlines/:id/like（toggle）
    S-->>D: {liked, likeCount}
    D->>D: 更新按钮态与计数

    U->>D: 输入评论（≤500字），可先点回复设 replyTo
    D->>S: POST /api/headlines/:id/comments {content, parentCid}
    D->>S: loadComments 重新拉取
    D->>D: comment_count 更新为列表长度

    U->>D: 删除评论（本人或管理员）
    D->>U: confirm 二次确认
    U->>D: 确认
    D->>S: DELETE /api/comments/:cid（子回复级联）
    D->>S: loadComments 重新拉取
```

## 5. 发布头条流程

```mermaid
flowchart TD
    A[/publish 路由/] --> B[Publish.vue onMounted<br/>GET /types 默认选第一项]
    B --> C[填写标题 maxlength=100<br/>内容 ≤5000 字实时统计]
    C --> D{前端校验}
    D -- 标题/内容空 或 超长 或 未选类型 --> E[显示 err 中止]
    D -- 通过 --> F[POST /api/headlines]
    F --> G{code?}
    G -- 0 --> H[router.push /headlines/新id<br/>直达详情]
    G -- 非0 --> I[catch 显示服务端 msg]
```

## 6. 我的头条管理流程（行内编辑）

```mermaid
flowchart TD
    A[/mine 路由/] --> B[GET /types + load]
    B --> C[GET /headlines?uid=me&keyword&typeId&page&pageSize]
    C --> D[渲染卡片列表 + 分页]
    E[修改按钮] --> F[startEdit 置 editing<br/>卡片切编辑态，类型只读]
    F --> G[PUT /headlines/:id title,content]
    G --> H{成功?}
    H -- 是 --> I[flash 修改成功 + load]
    H -- 否 --> J[err 显示]
    K[删除按钮] --> L{confirm 二次确认?}
    L -- 确认 --> M[DELETE /headlines/:id 级联删点赞评论]
    M --> N[flash 删除成功 + load]
    L -- 取消 --> O[中止]
```

## 7. 修改密码流程

```mermaid
flowchart TD
    A[/profile 路由/] --> B[GET /auth/profile 展示资料]
    C[填旧密码/新密码/确认] --> D{前端校验}
    D -- 未填完整 或 两次不一致 --> E[err 提示]
    D -- 通过 --> F[PUT /auth/password]
    F --> G{成功?}
    G -- 是 --> H[okMsg 成功提示<br/>1.5s 后清除 token/user<br/>跳转 /login 强制重登]
    G -- 否 --> I[err 服务端 msg]
```

## 8. 管理后台流程（role=1）

```mermaid
flowchart TD
    A[/admin 路由/] --> B{me.role === 1?}
    B -- 否 --> C[不加载任何数据]
    B -- 是 --> D[默认 Tab users<br/>GET /users + /stats/users]
    E[switchTab] --> F{tab?}
    F -- users --> D
    F -- headlines --> G[GET /admin/headlines?keyword&uid]
    F -- types --> H[GET /types]
    F -- notices --> I[GET /notices]
    F -- hot --> J[GET /stats/hot?sort&page&pageSize]
    F -- comments --> K[GET /admin/comments?hid&uid&keyword]
    G --> L[行内编辑 PUT /headlines/:id<br/>删除 DELETE /headlines/:id]
    H --> M[新增 POST /types<br/>改名 PUT /types/:id<br/>删除 DELETE /types/:id]
    I --> N[发布 POST /notices<br/>修改 PUT /notices/:id<br/>删除 DELETE /notices/:id]
    K --> O[删除 DELETE /comments/:id]
    L & M & N & O --> P[flash 成功提示 + 重载当前 Tab]
```

## 9. 统一请求/响应处理流程（api.js，异常驱动）

```mermaid
flowchart TD
    A[页面调用 api.get/post/put/del] --> B[request: fetch /api + path<br/>附带 Bearer token（同源，Vite 代理转发 :3000）]
    B --> C{res.json 可解析?}
    C -- 否 --> D[throw 服务器响应异常]
    C -- 是 --> E{json.code === 0?}
    E -- 是 --> F[返回 json.data 给页面]
    E -- 否 --> G[throw Error json.msg]
    F --> H[页面渲染数据]
    D & G --> I[页面 try/catch<br/>err.value = e.message 展示]
```
